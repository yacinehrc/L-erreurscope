# L'ERREURSCOPE

<img width="1024" height="572" alt="erreurscope_img" src="https://github.com/user-attachments/assets/acc4d79b-24b0-4f2e-822e-2bcf17095011" />

> L'Erreurscope est un gadget connecté inspiré de Rick & Morty développé pour le Workshop EPSI B2, qui prédit trois événements quotidiens pour évaluer la chance de l'utilisateur.
En cas de jour de chance, une IA diffuse via haut-parleur des mauvais compliments cyniques et piquants. À l'inverse, lors d'un jour de malchance, l'appareil contrebalance en distillant de bons compliments réconfortants.
